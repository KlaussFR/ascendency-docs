# Menu and keybinds

Once Discord overlay is live, the in-game panel is the same dark lavender UI as the loader.

- Open / close: `+` or Numpad + (rebind in Settings). The menu key cannot be cleared.
- Tabs: Aim, Visuals, World, Settings.
- Drag the panel from the header. Drag name / weapon / distance labels in the Visuals preview to place ESP text.
- Player toggle can take a keybind. Escape cancels capture. Backspace clears a feature bind.
- Colors last for the session. Restore default preferences resets them.

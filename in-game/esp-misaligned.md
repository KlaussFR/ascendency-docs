# ESP misaligned

Boxes or names sitting off the player usually means resolution / Discord overlay size, not a bad bind.

1. Match in-game resolution to the desktop. Do not use a stretched res Discord cannot overlay.
2. Use borderless. Exclusive fullscreen will offset or hide the layer.
3. If you changed Windows DPI scaling, set Discord and the game to the same scale (100% is safest).
4. Restart the loader after any resolution change so the shared swapchain can rebuild.

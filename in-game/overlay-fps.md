# Overlay FPS

Stutter or a low overlay cap is almost always Discord overlay or exclusive fullscreen, not the aim loop.

1. Borderless window — never exclusive fullscreen.
2. Discord hardware acceleration on.
3. Unpin Discord overlay widgets.
4. On Windows 11 let Ascendency launch Discord with direct composition disabled.
5. Close NVIDIA overlay / Medal / Xbox Game Bar if they are also drawing.

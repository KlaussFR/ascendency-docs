# Download and login

How to get the Ascendency loader and sign in with your license.

{% stepper %}
{% step %}
### Get the loader

Download the latest loader from the Ascendency Discord. Do not run copies from random resellers or old mirrors.

The file is `rob_run_handshake.exe`.
{% endstep %}

{% step %}
### Close extras

Fully quit Discord from the tray, close other overlays (NVIDIA, Medal, Steam overlay if it fights Discord), and pause heavy antivirus scans for a minute.
{% endstep %}

{% step %}
### Run as administrator

Right-click the exe → **Run as administrator**. The splash should open on a dark screen with the Ascendency mark.
{% endstep %}

{% step %}
### Enter your license

When the loader asks for a key, paste the license from your purchase. It is saved locally so you should not need to type it every launch.
{% endstep %}

{% step %}
### Wait for overlay

On Windows 11 the loader restarts Discord with overlay flags. Wait until Discord is back and the overlay is live before you expect the menu.

{% hint style="warning" %}
If the splash sits on “connecting to auth”, see [Slow / infinite loading](../errors/slow-loading.md).
{% endhint %}
{% endstep %}
{% endstepper %}

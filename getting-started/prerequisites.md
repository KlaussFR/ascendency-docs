# Prerequisites

Install these once. Missing runtimes look like random crashes or a splash that never finishes.

- Windows 10 or Windows 11, 64-bit
- Discord desktop stable (`Discord.exe`) — not the browser, not a random portable build
- Administrator account
- Visual C++ Redistributable (x64 and x86, latest)
- DirectX End-User Runtime
- Game Overlay enabled in Discord (see [Discord setup](../overlay/discord-setup.md))

[Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) · [DirectX runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35)

{% hint style="info" %}
Reboot after the runtimes finish installing. Then run the loader as administrator.
{% endhint %}

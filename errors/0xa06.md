# 0xA06 — KeyAuth failed

License, app version, or session token was rejected.

1. Paste the full key with no extra spaces.
2. Fix Windows date and time (automatic time).
3. Delete `%LOCALAPPDATA%\asc\cred.json` and login again.
4. Turn off VPN for the first login.
5. Expired or shared keys need a new license or a HWID reset from staff.

# 0xA01 — Driver failed

The kernel driver did not come up. Most often this is missing admin, antivirus blocking the load, or a leftover driver from a previous crash.

1. Right-click the loader → Run as administrator.
2. Reboot once so a half-loaded driver is gone.
3. Add an exclusion for the folder that contains `rob_run_handshake.exe`.
4. Close other cheats, spoofers, and kernel tools.
5. If it still fails, send the console lines around Initialize / Open device in a ticket.

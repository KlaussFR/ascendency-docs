# 0xE1 / 0xE2 — Overlay

Discord is running but the overlay host never attached.

1. Follow Discord setup: new overlay on, legacy off, hardware acceleration on.
2. Let the loader start Discord. Do not open Discord yourself first on Windows 11.
3. Close Discord Canary / PTB.
4. Unpin overlay widgets.
5. If the console says no overlay hwnd, the game is likely exclusive fullscreen.

# Slow / infinite loading

Splash stuck on connecting to auth, starting overlay, or waiting for Discord.

1. Stuck on **connecting to auth** — internet, VPN off, clock correct. See [0xA06](0xa06.md).
2. Stuck on **starting overlay** — Discord is restarting on Windows 11. Give it up to a minute.
3. Stuck on **Waiting for Discord overlay** — overlay is not enabled. [Discord setup](../overlay/discord-setup.md).
4. Antivirus inspecting the exe can stall downloads. Exclusion, then relaunch.
